Runs entirely in your browser — nothing is uploaded anywhere. A small language model is downloaded (and cached) the first time a new language is detected. This feature requires Chrome 138 or later.

The offset shifts subtitle timing to match the video without editing the subtitle file. Enter the frame-accurate timecode burned into the start of the video (h:mm:ss:ff) — it's converted to real seconds using the loaded subtitle file's own declared frame rate. A positive value shows subtitles that many seconds earlier than their file timestamps; negative delays them. Hit ± to flip the sign, or edit the field directly.

Keyboard shortcuts (once a video is loaded, and you're not typing in a field): Space/K play/pause · ←/→ step back/forward roughly one frame (an approximation — HTML5 video can't reliably report true frame rate, so this steps by 1/30s, drifting slightly on 24fps/25fps sources) · Shift+←/Shift+→ jump 5 seconds · L fast-forward, press again to speed up (2x → 4x → 8x) · J rewind similarly — note this is simulated by rapid backward seeking, not true reverse playback, since browsers don't reliably support that. This function tends to run away on itself, so I'd use it sparringly. Clicking any line in the subtitle list jumps the video to that line, honoring the current offset.
