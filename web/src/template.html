Shortcuts & help

Keyboard (QC tab)

  • SpacePlay / pause (always back to normal speed)
  • KPause
  • ← →Back / forward one frame
  • Shift+← →Jump 5 seconds
  • ⌥ Option+← →Jump 5 minutes
  • ↑ ↓Previous / next subtitle event (follows the event filter or search)
  • LPlay; press again for 2× → 4× → 6×. From reverse, one step back towards normal play
  • JReverse at 2×; press again for 4× → 6×. While playing forward, one step slower (1× → ◀◀ 2×). Reverse has no sound
  • Ctrl/⌘+scrollZoom the waveform bar
  • Shift+scrollMove along the waveform bar

Waveform bar

  • Press or drag on the bar to move the playhead.
  • Click a subtitle block to select it in the event list; clicking an event in the list jumps there.
  • The handle underneath shows the visible part of the video: drag it to move (the playhead follows), drag its ends to zoom between 5 seconds and the whole video.
  • The channel menu picks which audio is drawn (Auto: stereo summed, channel 3 for 6/8 channels).

Matching

  • Selecting a video lists the subtitle files whose names match it (production code, season/episode or episode title).
  • “Matched only / All files” (top right) hides or shows files without a match, on both tabs.
  • Switching subtitle files keeps the playback position; switching episodes keeps the same language when available.

Offset & timing

  • The offset is the timecode of the video's first frame. It's filled in automatically when the video has a timecode track; otherwise type the burned-in start timecode (hh:mm:ss:ff).
  • A typed offset is remembered for that video. ± flips the sign.
  • The offset is converted with the subtitle file's own frame rate; check it against the video's frame rate shown below the player.

Other

  • Translate uses Chrome's on-device translator (Chrome 138+); a small model downloads the first time a language is used.
  • Everything runs locally; nothing is uploaded.
