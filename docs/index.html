Subtitle QC

Language conform and QC for subtitle deliveries, with a frame-accurate player that plays ProRes, H.264 and HEVC.

Install

  1. Unzip Subtitle-QC.zip

    Double-click it in your Downloads folder.

  2. Move Subtitle QC to Applications.
  3. Open it the first time

    The app isn't signed with an Apple Developer ID, so macOS asks once.

    macOS 13 and 14: right-click the app, choose Open, then Open again.

    macOS 15: open it once (it will be blocked), then go to System Settings › Privacy & Security and click Open Anyway.

What it does

  • Checks a subtitles folder (TTML, IMSC, iTT, DFXP, WebVTT) against the language code list: labelled, expected and detected language, Full / Forced / SDH, cue checks.
  • Matches each subtitle file to its episode video by file name.
  • QC player with a waveform bar, subtitle events, and timecode from the video's own timecode track.
  • J / K / L shuttle, frame stepping with ← →, and ↑ ↓ to jump between subtitle events.
Reads the folders you choose and never changes your files. Works offline.
